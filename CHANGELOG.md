# Changelog

All notable changes to Free Shipping Notice are documented in this file.

## [1.0.0] - 2026-09-01

### Added

- Remaining amount notification for free delivery.
- Separate display settings for the offcanvas cart, cart page, and checkout confirmation page.
- Sales-channel-specific free shipping thresholds.
- Currency conversion based on the configured Shopware currency factor.
- Opt-out settings for shipping methods, customer groups, and currencies.
- Customizable storefront text through Shopware snippets.
- Default English and German translations.
- Cleanup of plugin configuration and edited snippet data during uninstall when user data is not retained.
- Unit tests for threshold calculation, exclusions, multiple deliveries, free delivery, and currency conversion.
